# Portfolio HTML/CSS

Site de 5 pages en HTML5 et CSS3 : un CV, un formulaire de contact et trois pages sur la trilogie Spider-Man avec Tom Holland.

## Pages

- **CV** (page d'accueil) : parcours, compétences et téléchargement en PDF
- **Contact** : formulaire de contact
- **Homecoming** (2017)
- **Far From Home** (2019)
- **No Way Home** (2021)

## Technologies

- HTML5
- CSS3, code validé W3C
